# Project Overview

This is a small Python command-line application used for practicing Claude Code workflows.

## Development

- Use Python 3.
- Run the application with `python manual_test.py`.
- Run all tests with `python -m pytest`.

## Testing

- Run the test suite after code changes.
- Do not consider a task complete if tests are failing.
- Keep tests in `test_manual_test.py`.

## Coding Guidelines

- Keep the implementation simple and readable.
- Handle invalid user input gracefully.
- Do not modify unrelated files.

## Git Workflow

- Prefer feature branches for code changes.
- Review diffs before committing.
- Do not commit failing tests.
- Do not add `hello.py` unless explicitly requested.
